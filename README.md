# 🌐 Nexus — Social Media Platform

**Nexus** is a modern full-stack social media application built with **React, Next.js, Express.js, and MongoDB**.  
It allows users to create posts, interact with others, manage their profiles, and enjoy a fast, responsive social networking experience.

---

## 🚀 Features

- 👤 User authentication and authorization
- 📝 Create, edit, and delete posts
- ❤️ Like and interact with posts
- 💬 Comment on posts
- 🖼️ Upload profile pictures
- 👥 User profiles
- 📱 Fully responsive design
- 🎨 Modern UI built with Tailwind CSS

---

## 🧩 Tech Stack

| Category | Technology |
|----------|------------|
| Frontend | React, Next.js, Tailwind CSS |
| Backend | Express.js, Node.js |
| Database | MongoDB |
| Authentication | JSON Web Token (JWT) |
